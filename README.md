打开 `index.html` 查看完整报告。

## 更新报告

编辑 `build.py`，必要时更新 `site_selected_videos.json`，然后运行：

```sh
python3 build.py
```

生成的 `index.html` 可直接通过浏览器打开，无需安装依赖。
